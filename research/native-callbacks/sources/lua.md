- L-S1 Lua errors are longjmp: manual.of v5.4.6 §4.4 "Internally, Lua uses the C longjmp facility to handle errors. (Lua will use exceptions if you compile it as C++...)" https://raw.githubusercontent.com/lua/lua/v5.4.6/manual/manual.of (same in v5.5.0)
- L-S2 error outside protected env aborts host: same §4.4 "If an error happens outside any protected environment, Lua calls a panic function ... and then calls abort, thus exiting the host application."

- L-S5 yield error: ldo.c v5.4.6 "attempt to yield across a C-call boundary"; manual §4.5 "Lua raises an error whenever it tries to yield across an API call, except for three functions: lua_yieldk, lua_callk, and lua_pcallk." and "the callee function cannot return to the original function, because its frame in the C stack was destroyed by the yield. Instead, Lua calls a continuation function"
- L-S6 count hook: manual "The count hook is called after the interpreter executes every count instructions. This event only happens while Lua is executing a Lua function." ; lua.c `luaL_error(L, "interrupted!")` from hook
